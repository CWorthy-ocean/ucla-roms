The BGC output files (``_bgc``, ``_bgc_avg``, ``_bgc_dia`` and ``_bgc_dia_avg``) are now closed after they are created. Each new file used to keep a netCDF file handle open until the end of the run (on rank 0 with ``PARALLEL_IO``, on every rank without it), so a run that writes many BGC files could reach the limit on open files.
- Without ``PARALLEL_IO``, the BGC writers also no longer close a netCDF file in steps without output. Since forcing files stay open across records (#429), that close could hit a forcing file and stop the run with ``Not a valid ID`` at its next record.
