Experimental, in development: the optional namelist group ``SL_ADV_SETTINGS`` (``sl_adv``, ``sl_c_lo``, ``sl_c_hi``, ``sl_cmax``, ``sl_diag``; requires ``IMEX_IGW``) for swept-volume advection on faces with a large 2-D Courant number.
- So far T, S and the passive tracers stepped with the dynamics take the swept flux on those faces (momentum is still stock, so the step limit does not change yet); ``sl_adv = .true.`` reports the hot faces on an ``SL`` line, and a namelist without the group runs as before.
