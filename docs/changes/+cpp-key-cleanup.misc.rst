CPP keys that nothing defined, or that were always set one way, are removed from the source, with the code they switched off; results are unchanged. ``SOLVE3D`` and ``TIDES`` are no longer needed in ``cppdefs.opt`` (the model is always three-dimensional, and tides are set in ``TIDAL_FRC_SETTINGS``); defining them does nothing.
- Always on: ``SOLVE3D``, ``EXACT_RESTART``, ``CORR_COUPLED_MODE``, ``EXTRAP_BAR_FLUXES``, ``IMPLCT_NO_SLIP_BTTM_BC``, ``VAR_RHO_2D``, ``SEA_ICE_NOFLUX``, ``PARALLEL_FILES``, ``EXCHANGE`` and ``MPI_SILENT_MODE``, plus switches defined inside single source files. ``SOLVE3D`` and ``EXACT_RESTART`` stay defined for older analytical set-up files (``ana_*.h``) that test them.
- Never defined: ``M2NUDGING``, ``M3NUDGING``, ``TNUDGING``, ``ANA_SST``, ``NONTRAD_COR`` and about sixty more macros, and the unused files ``transp_nodes.F``, ``compute_message_bounds.h``, ``compute_starts_counts.h``, ``tri_diag_w.h`` and ``ana_cdr_frc.h``.
