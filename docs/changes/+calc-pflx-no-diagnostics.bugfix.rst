``calc_pflx = .true.`` now computes the baroclinic pressure fluxes without the ``DIAGNOSTICS`` CPP key. Before, a build without ``DIAGNOSTICS`` (the default in C-Star Forge blueprints) never computed them: the ``up`` and ``vp`` fluxes extracted for child grids were zero, sponge tuning (``ub_tune``) tuned against zero fluxes, and the slow fields in restart files were zero.
