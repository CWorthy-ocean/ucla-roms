Five unused CPP keys are retired and their code removed: ``AKIMA`` (Akima horizontal tracer advection in the predictor step), ``LMD_DDMIX`` (double-diffusive mixing), ``MERGE_OVERLAP`` (merging overlapping KPP surface and bottom boundary layers), and the unfinished NHMG diagnostics ``DIAGNOSTICS_NHMG`` and ``NHMGDIAG``, which stopped every run. A ``cppdefs.opt`` that defines one now stops the build with an error that names the key; delete the line (an ``#undef`` line is harmless).
