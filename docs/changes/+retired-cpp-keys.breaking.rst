Twenty-two unfinished or experimental CPP keys are retired and their code removed: most of them no longer compiled, and ``AKIMA_V`` and ``BBL`` had no effect. A ``cppdefs.opt`` that defines one now stops the build with an error that names the key; delete the line (an ``#undef`` line is harmless).
- ``TS_DIF4`` with ``EASTERN_WALL``, ``WESTERN_WALL``, ``NORTHERN_WALL`` and ``SOUTHERN_WALL``; ``MY25_MIXING``, with its namelist key ``akq_bak``; ``NON_TRADITIONAL``; ``DIURNAL_SRFLUX``; ``ALLOW_SINGLE_BLOCK_MODE``; ``PRINT_TILE_RANGES``; ``BIO_1ST_USTREAM_TEST``; ``AKIMA_V``; ``BBL``; ``ANA_BRY``; ``TAU_CORRECTION``.
- The boundary schemes ``OBC_M2ORLANSKI`` (use ``obc_m2`` in ``OPEN_BOUNDARY_SETTINGS``), ``OBC_M3SPECIFIED`` (use ``obc_m3``), ``OBC_TSPECIFIED`` (use ``obc_t``), ``LEGACY_ORLANSKI`` and ``OBC_Z2ORLANSKI``, and the boundary data of the vertical velocity at the southern and northern sides (``W_FRC_BRY``, ``OBC_WSPECIFIED``).
- Keys that still compiled and changed the results: ``TR`` (experimental barotropic-coupling flux weights), ``ISWAKE_XXX`` (constant-flux inflow at the western boundary), and ``BULK_DIFFERENCE`` and ``INT_AT_W_POINTS`` (broken: they skipped the KPP bulk Richardson number integral). A configuration that defined one of them runs the default code once the line is deleted.
