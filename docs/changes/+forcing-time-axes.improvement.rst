ROMS now reads the time axes of classic-format (CDF-1, CDF-2, CDF-5) forcing files in 8-KiB blocks instead of one file-system block (4 MiB on Lustre) per time value, at start-up and whenever a run reaches a new forcing file, so finding forcing records no longer reads gigabytes; results are unchanged.
- On a Pacific MARBL run on 2 nodes from a cold cache, the forcing search before the first record drops from 29-36 s to 7-8 s.
