``imex_mix_split = 2`` in ``IMEX_IGW_SETTINGS`` applies the lateral mixing ahead of the IMEX corrector's implicit solve (momentum from this step's explicit state, tracers from the new level), so runs with ``imex_obc_mode = 'modal'`` keep the full sponge (``v_sponge`` of the grid spacing in m divided by 10) at long time steps. The default stays 1.
