History files (``_his``) hold the passive tracers (``passive_tracer<n>``) and the ``CDR_LITE`` tracers (``CDR_OAE_ALK<n>``, ``CDR_OAE_DIC<n>``, ``CDR_DOR_DIC<n>``), unless the new key ``wrt_passive`` (``TS_OUTPUT_SETTINGS``, default ``.true.``) is ``.false.``. Before, they were there only with MARBL, when ``marbl_tracers_to_write`` was empty or named them; that list no longer affects them in history files. The averages are unchanged.
