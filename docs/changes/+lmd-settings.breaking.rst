The vertical mixing of Large, McWilliams and Doney (1994) is now set in the namelist group ``VERTICAL_MIXING_SETTINGS``, in place of six CPP keys: ``lmd_mixing``, ``lmd_kpp``, ``lmd_bkpp``, ``lmd_nonlocal`` and ``lmd_rimix`` (default ``.true.``, as in the template ``cppdefs.opt``) replace ``LMD_MIXING``, ``LMD_KPP``, ``LMD_BKPP``, ``LMD_NONLOCAL`` and ``LMD_RIMIX``, and ``lmd_convec`` (default ``.false.``) replaces ``LMD_CONVEC``.
- **A case built without** ``LMD_MIXING`` **(or without one of the other keys) must now set the matching setting to** ``.false.``: with the defaults it runs with that mixing, and nothing stops it. An analytical case with ``ana_vmix = .true.`` stops until it sets ``lmd_mixing = .false.``.
- A ``cppdefs.opt`` that defines one of the six keys stops the build with an error that names the setting; delete the line (an ``#undef`` line is harmless).
- ``lmd_convec = .true.`` needs ``lmd_mixing`` and ``lmd_rimix``: the run stops otherwise (before, ``LMD_CONVEC`` without ``LMD_RIMIX`` read a Richardson number that was never computed). Without ``lmd_mixing`` the other settings are not used, and ``lmd_nonlocal`` is not used without ``lmd_kpp`` (before, ``LMD_KPP``, ``LMD_BKPP``, ``LMD_NONLOCAL`` and ``LMD_RIMIX`` without ``LMD_MIXING``, and ``LMD_NONLOCAL`` without ``LMD_KPP``, did not change the solution); ROMS prints the settings at start-up, with a line naming those not used.
- The ``hbls`` and ``hbbl`` variables of the history, averages and restart files exist only with ``lmd_kpp`` and ``lmd_bkpp`` in effect, as with the keys. The ``CPPS`` attribute of output files no longer lists these keys.
- The never-defined CPP switch ``LIMIT_UNSTABLE_ONLY`` of the KPP velocity scales was removed.
