0.6.1
----------


Bug Fixes
~~~~~~~~~


- Passive extract/create loops used do indt=isalt+1,nt_passive, which did not cover iTandS+1 … iTandS+nt_passive. (`#347 <https://github.com/CWorthy-ocean/ucla-roms/pull/347>`_)
- CDR OAE loops used an upper bound of +nt_cdr_oae instead of +2*nt_cdr_oae, so only part of each ALK/DIC pair range was visited. (`#347 <https://github.com/CWorthy-ocean/ucla-roms/pull/347>`_)
- Indexing now uses iTandS consistently for passive, CDR OAE, CDR DOR, and BGC loops (write and non-PIO create paths). (`#347 <https://github.com/CWorthy-ocean/ucla-roms/pull/347>`_)
