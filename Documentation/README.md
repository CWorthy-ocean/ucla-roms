# Historical notes

These files are notes, scripts and examples from upstream UCLA ROMS, kept for reference. They are not maintained, and much of what they describe (`roms.in`, `param.h`, the per-module `*.opt` settings files, the old example and machine setups) no longer exists in this repository.

The current documentation is at https://cworthy-ucla-roms.readthedocs.io (source in `docs/`).
